TARJETAS SANITARIAS

Si marcas esta casilla, sólo los profesionales seleccionados verán a este paciente. Para todos los demás, será invisible, salvo que tengan el permiso Ver todos los pacientes.

Por favor, asegúrate de haber incluido el documento firmado en la lista de adjuntos del paciente.

El paciente da su consentimiento para que se le pueda enviar información promocional y ofertas publicitarias.

Con la casilla marcada, la configuración de recordatorios del centro se aplicará a las citas de este paciente. Con la casilla desmarcada, las citas que se creen para este paciente no llevarán recordatorios de ningún tipo.
